# --- What the dotfiles themselves reach for ---
# gh: the gh() wrapper and bin/git-credential-gh-user route accounts through
# it, so a box without gh cannot resolve an account at all. Ubuntu's build
# trails upstream badly; add GitHub's own apt repo and this same entry
# installs the current release instead — see
# .claude/rules/packages.md for the one-time source setup.
gh
# bats: runs this repo's own suite (bats tests) on the machine itself
bats
# python3: bin/denyguard and bin/workset are sh wrappers around a python3
# heredoc, and denyguard is the one hook wired fail-closed — without python3
# it refuses every Bash call in a profile that wires it
python3
# minisign: verifies the signed release bin/postbox installs
minisign
# xdg-open, which .aliases uses to provide `open` off macOS
xdg-utils
# clipboard — .aliases and .functions guard on both names
xclip
xsel
lsof
# fc-list, which bin/has-glyphs uses on Linux
fontconfig

# transmission-cli is deliberately macOS-only, not missing from Ubuntu: the
#   package exists here and does carry transmission-remote (as well as
#   create/edit/show — only transmission-daemon is split into its own
#   package), but the Transmission instance it drives runs on the mac, so a
#   Linux box would have nothing to talk to. Install it by hand if that
#   ever stops being true.
# rclone + fuse3: tailnet mount — on Linux it FUSE-mounts (rclone mount needs
#   fusermount3); macOS uses rclone nfsmount instead. Not applicable to the
#   wsl class, which runs no tailscaled of its own.
# yt-dlp is deliberately absent: Ubuntu 24.04 ships 2024.04.09 against the
#   Brewfile's current build, and a stale yt-dlp breaks on every site change.
#   Install it with uv/pipx, where it can track upstream.
# awscli is not in Ubuntu 24.04 at all — use AWS's own v2 installer.
# lazygit and k9s are not in Ubuntu's repos — install manually if wanted
# actionlint, cloudflared, and countdown are not in Ubuntu's repos either — install manually if wanted
# tailscale is not in Ubuntu's repos either (needs pkgs.tailscale.com's apt source) — install manually; bin/tailnet's userspace daemons need its tailscaled
# espanso is not in Ubuntu's repos — install the .deb from its GitHub releases
# jadx (Android decompiler) is not in Ubuntu's repos — unzip the jadx-<ver>.zip from github.com/skylot/jadx releases (needs a JRE)
# antigravity-cli (agy) is not in Ubuntu's repos — install with Google's script, which puts agy in ~/.local/bin:
#   curl -fsSL https://antigravity.google/cli/install.sh | bash
