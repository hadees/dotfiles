# User memory — personal profile

This is the personal Claude Code profile (`~/.claude-hadees`), selected
automatically by the `claude()` wrapper when the repo's origin belongs to the
personal GitHub account. It has its own login, settings, and session history.

Shared preferences come from the first import; machine-local notes from the
second. There is deliberately no work memory here — that is ICA-profile only.
