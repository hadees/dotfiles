# User memory — ICA profile

This is the work Claude Code profile (`~/.claude`, the default config dir),
selected automatically by the `claude()` wrapper when the repo's origin
belongs to a work org. It keeps the existing login, plugins, and session
history.

Shared preferences come from the first import. The second is machine-local
notes, generated by chezmoi and never committed. The third carries
work-specific notes (accounts, orgs) and is deployed only by the private
overlay repo — this file is public, so it must not name them. Any import is
simply unresolved on a machine that lacks it.
