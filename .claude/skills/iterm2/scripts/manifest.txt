# Machine-checkable facts this skill records about iTerm2.
#
# Everything here was read off an installed iTerm.app rather than recalled,
# and scripts/verify.sh re-reads it the same way. That is the whole point of
# the file: prose rots silently when the app updates, but a list of names
# that either are or are not in the bundle cannot.
#
# Verbs:
#   version <v>     the release this skill was researched against
#   sdef <literal>  substring that must appear in Contents/Resources/iTerm2.sdef
#   binstr <s>      exact string in the main executable (a defaults key,
#                   a Dynamic Profile key, a user-visible sentence)
#   util <name>     executable in Contents/Resources/utilities
#   info <k> <v>    Info.plist key that must still read exactly <v>
#   tipcount <n>    how many features iTerm2's own tour (the bundled it2tip)
#                   lists; the only verb here that notices an ADDITION
#   bundle <N.app>  sibling app bundle; advisory only, never fails the run
#
# Add a fact here the moment you rely on it in a reference file, and delete
# it when the reference stops claiming it. A fact nobody documents is noise;
# a claim nothing checks is the failure mode this skill exists to prevent.

# --- iTerm2's own feature inventory ------------------------------------
# it2tip is a Python script carrying the app's whole feature tour, one entry

# here that can notice a feature being ADDED rather than removed — every

# `.../Contents/Resources/utilities/it2tip` and read what is new.

# --- Claude Code integration (3.7) -------------------------------------
# iTerm2 3.7 ships cc-status, a hook binary that turns Claude Code hook
# payloads into Session Status rows, and it2, the CLI it drives. Both are
# undocumented on iterm2.com; bin/cc-status-shim sits in front of cc-status
# and depends on exactly these facts: the payload keys cc-status reads, the
# it2 flag it stores the task count under, the detail text and colours it
# paints, and the app's own symlink upkeep. Swift keeps strings of 15 bytes
# or fewer inline, so short literals (--status, --detail, set-status) are
# not findable here; everything below is 16 bytes or longer, or a colour.
util cc-status
util it2
utilstr cc-status background_tasks
utilstr cc-status notification_type
utilstr cc-status permission_prompt
utilstr cc-status last_assistant_message
utilstr cc-status --background-tasks
utilstr cc-status 1 background task running
utilstr cc-status #00d75f
utilstr cc-status #5f87ff
utilstr cc-status #888888
utilstr cc-status #ff9500
utilstr it2 --background-tasks
utilstr it2 ITERM_SESSION_ID
binstr ccStatusSymlinkIsHealthy
binstr ensureCCStatusSymlink
binstr utilities/cc-status
binstr com.iterm2.set-status
binstr Toolbelt.Session Status
binstr * `status=TEXT`
